Walmart Visión se entrega como aplicación web de ejecución local.
El ZIP es el ejecutable de distribución correspondiente a este apartado de la pauta.
En este repositorio de GitHub el paquete ZIP ejecutable se descarga desde Releases (enlace y SHA-256 abajo) y el código fuente completo vive en Aplicacion/ y Aplicacion_Cliente/ en la raíz del repositorio.

En Windows x64 extraiga el ZIP completo y abra iniciar_cliente.cmd (puerto 8098) o iniciar_equipo.cmd (puerto 8095).
Incluye 8 casos de ejemplo precargados en la app cliente (botón «Probar un pasillo de ejemplo»).
Para ejecutar con Docker (disponible solo para la app del equipo), consulte la sección Docker del instructivo de instalación.
