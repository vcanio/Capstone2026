# Entregables del proyecto

La nueva distribución se publica en la Release avance-2026-10-20. Los ZIP, pesos y
documentos grandes no se agregan al historial Git. Consultar la
[guía de reproducción](../Documentacion/Replicar_proyecto.md) y el
[manifiesto de activos](../reproducibilidad/artefactos.json).

- Walmart_Lite_V2_20261020.zip: demo con cuatro modelos V1/V2 base.
- Walmart_Informe_20261020.zip: PDF, Word y HTML del informe histórico.
- Datos y modelos/resultados: instalables con preparar.py.

El paquete Walmart_Lite_Automatico_20261015.zip conserva la entrega V1 histórica
en el laboratorio; no se requiere para instalar la nueva distribución.
