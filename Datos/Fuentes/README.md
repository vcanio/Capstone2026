# Fuentes de datos

Las fuentes fotográficas completas se conservan en el entorno local, con procedencia, SHA-256 y relaciones de escenas/familias. No se incluyen en GitHub ni en el ZIP de inferencia.

El modelo vigente usa 519 fuentes train distintas en tres etapas; el último cierre utiliza 256 train y 11 val reales. Las listas históricas de octubre no describen el uso actual de cada imagen.
